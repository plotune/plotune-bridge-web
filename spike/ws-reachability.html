Bridge CAN browser → LAN WebSocket reachability

This page runs from an HTTPS origin and attempts a WebSocket connection to a Bridge CAN virtual device. It sends the contract hello request and records whether the connection opened, the response, any browser error and the close code. It is a spike, not a product transport.
